### install

npm i socket.io socket.io-client express fs-extra dayjs

Change IP-adress in *.env* to yours

### Server start 

node server/server.js

### Demo sender start

node client-sender/sender.js

### Or for Windows you can use scripts:

#### installing

install.bat

#### start ws-server

start-server.bat

#### start sender

start-sender.bat

### for Linux:

chmod +x install.sh
chmod +x start-server.sh 
chmod +x start-sender.sh

./install.sh
./start-server.sh
./start-sender.sh
